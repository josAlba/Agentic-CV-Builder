# Markdown Structure Guidelines

To ensure the extraction process works correctly, all files in `references/[PROFILE_NAME]/` must follow these structural patterns:

## 1. Profile (README.md)
The main entry point for personal information.
- **Title (H1):** Full Name.
- **Image:** Markdown image syntax `![alt](url)`.
- **Subtitle (H2):** Professional Title.
- **Header Line:** Contact details, location, and links separated by `|`.
- **Bio:** General professional summary.

## 2. Experience (experiencia_*.md)
One file per company or role.
- **Title (H1):** `Company Name | Role Name`.
- **Subtitle (H2):** Date range (e.g., `2021 - Actualidad`).
- **Description:** Summary of the role.
- **Section: Responsabilidades y Logros (H3/H4):** Bullet points of key achievements.
- **Section: Tecnologías Utilizadas (H3/H4):** Bullet points or comma-separated list of technologies.

## 3. Skills and Others (habilidades_y_otros.md)
- **Sections (H3):** `Carnets de Conducir`, `Habilidades Técnicas`, `Idiomas`, etc.
- **Technical Skills:** Categorized using bold labels (e.g., **Lenguajes Principales:**).

## 4. Projects (proyectos_personales.md)
- **Title (H1):** Section name.
- **Project Items (H3/H4):** Name of the project.
- **Description:** Summary.
- **Tech Stack:** Comma-separated or bullet points.
